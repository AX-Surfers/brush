# Brush — 화면 위 필기 오버레이

강의 중 화면에 바로 선을 그어 시선을 잡아두는 도구.

- **macOS** — `Brush.swift` 네이티브 앱. macOS 13 이상, 애플 실리콘 / 인텔 모두 지원.
- **Windows** — `brush.py` (Python + Qt). 그리기, 실행취소, 클릭 통과, 포인터, 확대와
  환경설정을 같은 흐름으로 제공합니다. Linux · macOS 에서도 실행할 수 있지만 전역 단축키와
  화면 캡처 세부 동작은 운영체제에 따라 다릅니다.

일반 필기에는 별도 권한이 필요하지 않습니다. **확대 도구는 화면 내용을 읽어야 하므로 macOS에서
처음 사용할 때 화면 기록 권한을 요청합니다.** 권한을 허용한 뒤 앱을 다시 실행해야 할 수 있습니다.

## 설치 (macOS)

### 방법 1 — 내려받기

[릴리스](https://github.com/AX-Surfers/brush/releases/latest)에서 `Brush.zip` 을 받아
압축을 풀고 `Brush.app` 을 `/응용 프로그램` 으로 옮깁니다.

인터넷에서 받은 앱이라 **첫 실행 때 한 번** macOS가 막습니다. Apple에 등록비를 내고
서명한 앱이 아니라서 그렇습니다 (열어보면 소스가 전부 이 저장소에 있습니다):

1. `Brush.app` 을 더블클릭 → 경고가 뜨면 닫기
2. 시스템 설정 → 개인정보 보호 및 보안 → 아래로 스크롤 → **"확인 없이 열기"**
3. 다시 더블클릭 → **열기**

터미널이 편하면 이 한 줄로 대신할 수 있습니다.

```sh
xattr -dr com.apple.quarantine /Applications/Brush.app
```

### 방법 2 — 직접 빌드 (경고 없음)

Xcode Command Line Tools (`xcode-select --install`) 만 있으면 됩니다.

```sh
git clone https://github.com/AX-Surfers/brush.git && cd brush && ./build.sh && open Brush.app
```

메뉴바에 ✏️ 가 생기면 실행 중입니다. 로그인 시 자동 실행하려면
시스템 설정 → 일반 → 로그인 항목에 `Brush.app` 추가.

## 설치 (Windows)

[Python 3.10 이상](https://www.python.org/downloads/windows/)이 필요합니다 (설치할 때
"Add python.exe to PATH" 체크). PowerShell 에서:

```
py -m pip install PySide6
py brush.py
```

콘솔 창 없이 띄우려면 `pythonw brush.py`, 로그인 시 자동 실행하려면 그 명령을 담은
바로가기를 `Win+R` → `shell:startup` 폴더에 넣습니다.

배포용 단일 실행 파일(`dist\Brush.exe`, Python 설치 없이 실행)이 필요하면:

```
py -m pip install pyinstaller
py -m PyInstaller --noconsole --onefile --name Brush brush.py
```

작업 표시줄 알림 영역에 ✏️ 가 생기면 실행 중입니다 (아이콘 클릭으로도 켜고 끄기).

## 조작

| 키 | 동작 |
|---|---|
| `⌥Z` (Windows `Alt+Z`) | 브러시 켜기 / 끄기 (어느 앱에서든) |
| 드래그 | 선택한 도구로 그리기 |
| `⌘Z` / `⇧⌘Z` | 실행취소 / 다시 실행 |
| `P` `A` `R` `T` `E` `C` | 펜 · 화살표 그리기 · 사각형 · 텍스트 · 지우개 · 클릭 |
| `⌥1`~`⌥6` | 마우스(클릭 통과) · 펜 · 화살표 그리기 · 사각형 · 텍스트 · 지우개 순서로 전환 (Windows `Alt+1`~`Alt+6`) |
| `⌥7` / `⌥8` | 레이저 포인터 / 화살표 포인터 |
| `⌥9` / `⌥0` | 원형 확대 / 사각형 확대 |
| `⌥⌘Z` | 실행취소 (클릭 모드용) |
| `ESC` | 현재 작업·이력을 모두 취소하고 마우스(클릭 통과) 모드로 전환 |

글자 단축키(`P`/`A`/...)와 `⌘Z`는 브러시 창에 포커스가 있을 때 쓰는 빠른 로컬 단축키입니다.
클릭 모드처럼 포커스가 밑 앱으로 넘어가도 동작해야 하는 전역 단축키는 환경설정에서 바꿀 수
있습니다. 토글 키를 제외한 전역 단축키는 브러시가 켜져 있을 때만 등록됩니다.

브러시를 켜면 화면 왼쪽에 세로 1열 툴바가 함께 뜹니다. 마우스(클릭 통과) / 펜 / 화살표
그리기 / 사각형 / 텍스트 / 지우개 / 레이저 / 화살표 포인터 / 원형 확대 / 사각형 확대 순서이며,
그 아래에 실행취소, 색상과 굵기 버튼 4개(4 · 8 · 14 · 22)가 있습니다. 툴바 배경을 드래그해
원하는 위치로 옮길 수 있습니다.

지우개는 픽셀이 아니라 **도형 단위**로 지웁니다 — 지나간 자리에 닿는 선·도형·텍스트가
통째로 사라집니다. 지우는 범위는 굵기 버튼을 따릅니다. `ESC`를 누르면 입력과 그림,
실행취소 이력까지 모두 버리고 밑 화면을 조작하는 마우스 모드로 전환합니다.

텍스트 도구로는 화면을 클릭한 자리에 바로 입력하고 `Enter` 로 확정합니다. 글자 크기도
굵기 버튼을 따라갑니다(기본 36pt, 최대 78pt).

실행취소는 획·도형·텍스트 하나 단위입니다. 지우개는 드래그 한 번이 실행취소 한 번입니다.
`ESC`로 취소하거나 브러시를 끄면 그림과 함께 실행취소 이력도 비워집니다.

**클릭 도구**를 고르면 그린 것은 화면에 남겨둔 채 마우스가 오버레이를 통과해 밑 앱을 그대로
쓸 수 있습니다. 다시 그리려면 `⌥2`(펜) 등으로 돌아오면 됩니다. 브러시를 완전히 끌 때는
`⌥Z`이고, 끌 때 그림은 지워집니다.
메뉴바(Windows 는 알림 영역) ✏️ 아이콘에서도 켜기/끄기·지우기·종료를 할 수 있습니다.

**레이저 포인터**와 **화살표 포인터**는 화면에 흔적을 남기지 않는 발표용 도구입니다. 크기와
색상은 환경설정에서 바꿀 수 있고 변경 즉시 현재 포인터에 반영됩니다. 다른 도구로 바꾸거나
Brush를 끄면 시스템 커서가 복구됩니다.

**원형 확대**와 **사각형 확대**는 두 방식으로 쓸 수 있습니다. 마우스를 움직이기만 하면 기본
렌즈가 포인터를 따라다닙니다. 원하는 영역을 드래그하면 실제 확대 결과를 미리 보면서 원형 또는
사각형 렌즈의 위치와 크기를 정할 수 있고, 버튼을 놓으면 그 자리에 고정됩니다. 짧게 클릭하면
고정을 풀고 다시 포인터 추적 방식으로 돌아갑니다. 두 방식 모두 휠 또는 트랙패드 스크롤로
`1.25×`~`8×` 범위에서 `0.25×`씩 계속 조절할 수 있습니다. 마지막 배율은 자동 저장되어 다음
확대의 시작값이 됩니다. macOS에서 화면 기록 권한이 거부되면 확대 렌즈에 권한 안내가 표시됩니다.
Windows의 실시간 자기 창 제외 캡처는 Windows 10 2004 이상을 권장하며, 지원되지 않는 환경에서는
재귀 화면을 피하기 위해 확대 진입 시점의 정적 화면을 사용합니다.

메뉴바 또는 알림 영역 메뉴의 **환경설정…**에서 모든 전역 단축키, 레이저 점 크기·색상,
화살표 포인터 크기·색상과 기본/마지막 확대 배율을 바꿀 수 있습니다. 설정은 재시작 후에도
유지됩니다. 중복되거나 다른 앱이 이미 쓰는 전역 단축키는 적용하지 않고 직전 설정을 유지합니다.

Windows 외의 플랫폼에서 `brush.py` 를 돌리면 전역 단축키는 잡히지 않고 트레이 아이콘으로만
켜고 끕니다 (macOS 는 네이티브 앱을 쓰면 됩니다).

## 구조

- `Brush.swift` — macOS 전부. 오버레이 + 캔버스 + 환경설정 + 화면 캡처 + 전역 단축키 + 셀프테스트
- `build.sh` — 두 아키텍처로 컴파일해 하나로 합치고 `Brush.app` 번들 생성 + 셀프테스트.
  `./build.sh --zip` 이면 배포용 `Brush.zip` 까지
- `brush.py` — Windows 판 전부. 같은 도구·환경설정·포인터·확대 구조를 PySide6로 옮긴 이식판

셀프테스트는 두 판 모두 같은 항목을 검사합니다.

```sh
./Brush.app/Contents/MacOS/Brush --selftest   # macOS
py brush.py --selftest                        # Windows
```
